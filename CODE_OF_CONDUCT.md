# Code of Conduct

This project expects respectful, constructive collaboration.

## Expected behavior

- Be direct, technical, and respectful.
- Assume good intent and focus on the work.
- Report security, privacy, or abuse issues responsibly.

## Unacceptable behavior

- Harassment, threats, discrimination, or doxxing.
- Deliberate disruption of technical discussions or project operations.
- Sharing secrets, sensitive customer data, or private incident details.

## Reporting

Report conduct concerns to support@debugbundle.com.
